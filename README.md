# LGT Race Entry Bot

LGTタイムアタックレースの「レーサーエントリー」をDiscordのチケット形式で受け付け、Googleスプレッドシートの名簿（1ページ目「LGTタイムアタックエントリー名簿」）へ自動反映するボットです。

## フォームの流れ

1. ユーザーが `/entry`（またはパネルのボタン）でエントリーチケット（専用プライベートチャンネル）を作成
2. Q1 名前 / Q2 街の電話番号（モーダル入力）
3. Q3 既に企業チームに所属しているか
   - はい → 所属企業チームを選択 → 最終確認へ
   - いいえ → Q4（アカデミー規約）
4. Q4 規約同意
   - 同意しない → 案内メッセージのみ表示し、「トップページに戻る」で最初からやり直し
   - 同意 → Q5 アカデミー選択（LGT公式 / 3NO1、既存メンバー一覧を表示）
5. Q6 選択したアカデミーに入会するか
   - いいえ → Q5に戻る
   - はい → 最終確認へ
6. 最終確認 → 「登録する」でスプレッドシートの1ページ目に1行追加（名前・街の電話番号・所属・登録日時）

所属チームの選択結果（企業チーム名 or アカデミー名）は、そのまま名簿の「所属チーム」列に反映されます。

## セットアップ

### 1. Discord Bot

1. [Discord Developer Portal](https://discord.com/developers/applications) でアプリケーションを作成し、Botを追加
2. `MESSAGE CONTENT INTENT` は不要（モーダル/ボタン/セレクトのみ使用）
3. Botに以下の権限を付与してサーバーに招待: `チャンネルの管理` `チャンネルを見る` `メッセージの送信` `メッセージ履歴を読む`
4. `.env` を作成し（`.env.example` を参照）、`DISCORD_TOKEN` `DISCORD_CLIENT_ID` `DISCORD_GUILD_ID` を設定

### 2. Googleスプレッドシート連携

1. Google Cloud Consoleでサービスアカウントを作成し、JSONキーを発行
2. 対象のスプレッドシートをサービスアカウントのメールアドレスに「編集者」として共有
3. `.env` に `GOOGLE_SERVICE_ACCOUNT_EMAIL` `GOOGLE_PRIVATE_KEY`（`\n` は改行としてそのまま貼り付けでOK） `SPREADSHEET_ID` を設定
4. スプレッドシートに以下のシート（タブ）をあらかじめ作成しておく
   - `LGTタイムアタックエントリー名簿`（A:名前 B:街の電話番号 C:所属チーム D:登録日時）
   - `LGTアカデミー`（A:名前 B:街の電話番号 C:予備1 D:予備2 E:備考）
   - `3NO1`（LGTアカデミーと同様）
   - `全レーサー名簿`（A:名前 B:レーサー情報）
   - `各レーサー情報`（A:名前 B:街の電話番号 C:所属チーム D:参加レースログ E:優勝タイトル F:ステータス G:備考）

   ※ 今回のエントリーフォームは1ページ目「LGTタイムアタックエントリー名簿」にのみ書き込みます。Q5で表示するアカデミーの既存メンバー一覧は `LGTアカデミー` / `3NO1` シートのA列から読み込みます。

### 3. インストール・起動

```bash
npm install
cp .env.example .env   # 値を編集
npm run deploy-commands
npm start
```

### 4. 運営パネルの設置

サーバー内で `/setup-panel` を実行すると、そのチャンネルに「エントリーチケットを開く」ボタン付きのパネルを設置できます。

### 5. 本部鯖（管理パネル）

エントリー受付とは別に、本部鯖（管理権限を持つスタッフのサーバー）でも同じBotを使えます。

1. Bot招待用URLで、本部鯖にも同じBotを招待する
2. `.env` に `HQ_GUILD_ID`（本部鯖のサーバーID）を設定
3. `npm run deploy-commands` を実行すると、本部鯖にだけ `/admin-panel` コマンドが登録される（エントリー鯖には登録されない）
4. 本部鯖で `/admin-panel` を実行すると、そのチャンネルに管理パネル（🔍名簿検索 / 🗑レーサー削除 / 🏆TA記録管理 / 📊統計表示）が設置される
5. パネルのボタンはすべて `STAFF_ROLE_ID` を持つメンバーのみ操作可能（未設定の場合は本部鯖の全員が操作可能になるため、必ず設定を推奨）

TA記録管理で入力した内容は「各レーサー情報」シートの参加レースログ欄に追記され、対象レーサーの行がまだ無ければエントリー名簿から基本情報を引いて自動作成されます。

## 企業チーム一覧

`src/config.js` の `COMPANY_TEAMS` に一覧を定義しています。追加・変更はここを編集してください。

## 補足

- 進行中のフォーム状態はメモリ上（`src/session.js`）で管理しています。ボットを再起動すると進行中の入力はリセットされます。
- チケットチャンネルはユーザー本人・運営ロール（`STAFF_ROLE_ID` 設定時）・ボットのみ閲覧可能です。
- 登録完了後はそのユーザーの送信権限をロックし、チャンネルは運営が手動でアーカイブ／削除してください。
